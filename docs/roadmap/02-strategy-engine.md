# 阶段 2：策略引擎 V3

状态：`COMPLETE`
完成日期：2026-07-18

## 目标

在阶段 1 的回测基础上，将经验评分升级为可解释、可校准、能识别市场环境的多因子策略。

## 计划范围

- 因子层：趋势、动量、均值回归、量价、波动率、流动性。
- 市场环境层：指数趋势、市场宽度和波动状态。
- 风控层：ATR 止损、移动止盈、最大回撤和持仓集中度。
- 多周期输出：1/5/10/20 日目标。
- 输出完整贡献明细，而不只返回总分和三条原因。
- Walk-forward 参数选择、样本外评估和参数敏感性测试。
- 将最终分数校准成历史概率区间；样本不足时不得展示伪精确概率。

## 核心指标

- 样本外胜率、平均收益、盈亏比。
- 最大回撤、夏普率、换手率和交易成本后收益。
- 不同市场阶段的稳定性。
- 相比沪深 300 和简单均线基准的增量价值。

## 反过拟合要求

- 不以单只股票或单一牛市阶段选择参数。
- 记录所有尝试，不只保留最佳结果。
- 参数小幅变化不应导致结果彻底反转。
- 策略复杂度增加必须带来稳定的样本外提升。

## Walk-forward 评估设计

- 输入至少两段连续时间：训练区间和严格晚于训练区间的验证区间。
- 参数选择只允许读取训练区间；当前先搜索买入阈值，因子权重参数化后复用同一选择接口。
- 验证区间前保留不少于 60 根日线作为指标预热，但预热期信号和收益不得进入验证结果。
- 候选参数按训练集的交易后平均收益、盈亏比、最大回撤和最小样本数综合排序；样本不足时拒绝选择。
- 输出必须同时保存每个候选的训练指标、最终选择、独立验证指标和成本假设，禁止只展示最优结果。
- 第一版采用单次时间切分建立正确边界，后续扩展为滚动多折 walk-forward 和参数敏感性矩阵。

### CLI 约定

```bash
python research.py walk-forward \
  000001 600519 300750 002594 601318 \
  --train-start 2024-01-01 --train-end 2025-06-30 \
  --validation-start 2025-07-01 --validation-end 2026-07-17 \
  --strategy v2 --thresholds 60,65,70,75,80 --horizon 20
```

默认只读取本地缓存。训练与验证之间不得重叠，验证集输出的 `evaluation_start` 必须等于或晚于 `validation-start`。

首版阈值选择分为：`平均净收益 + 0.25 × (截断到 3 的盈亏比 - 1) + 0.02 × 最大回撤`。这是可审计的研究排序规则，不代表最终目标函数；所有原始指标仍完整保留，避免单一综合分掩盖风险。

## 市场环境输入设计

- V3 的市场环境因子必须使用与股票信号日对齐的市场日线，任何晚于信号日的指数数据都不可见。
- 首版使用本地缓存的 `000300` 沪深 300 指数原始日线。股票与市场输入的复权方式分别显式指定，指数不得伪装成前复权数据。
- 研究 CLI 通过显式 `--market-code` 启用市场环境，不静默联网；市场缓存不足 60 根时按中性处理并降低置信度。
- V3 的实时接入必须复用同一个按日期截断的 scorer 工厂，禁止回测有市场环境而实盘缺失。

## 验收标准

- 实时评分与回测使用同一策略入口。
- 每个信号可展示因子贡献、市场环境和风险建议。
- 策略报告明确列出训练区间、验证区间、成本假设和样本数。

## 阶段结论

本阶段完成的是可审计的策略候选、基准和样本外验证能力，不是强行上线一个表现不稳定的新策略。V3 在扩展样本上显示潜力，但滚动窗口稳定性未达标，因此保留为研究候选；线上继续使用已修复且与回测共享纯函数入口的 V2。未来 V3 只有在新增样本外区间持续优于基准后才允许晋级。

## 实施记录

- 已新增 `strategy_v3.py` 候选引擎，包含趋势、动量、均值回归、量价、波动风险和市场环境六类贡献，总分上限 100。
- 已输出 ATR 风险计划，包括止损、止盈和移动止损参考值。
- V3 仍是研究候选，未接入实时监控。
- 单股真实初测 `600519` 表现没有优于 V2，因此明确拒绝直接上线。
- 已缓存 `000001`、`600519`、`300750`、`002594`、`601318` 在 2024-01-02 至 2026-07-17 的 614 根前复权日线。东方财富接口不稳定时，自动切换新浪数据源成功；缓存写入保持原子性。
- 五股 20 日横向对照（阈值 70）：V2 共 81 笔、胜率 53.09%、平均收益 +1.68%、盈亏比 1.6357；V3 共 74 笔、胜率 43.24%、平均收益 +0.49%、盈亏比 1.167。V3 没有达到替换 V2 的证据标准。
- 上述五股和完整时间段只能作为初始基线，不能在同一数据上调参后宣称优化有效；下一步按本节设计实现并运行独立训练/验证评估。
- 已新增 `walk_forward.py` 和 `research.py walk-forward`：训练/验证区间强制不重叠、验证前 60 根日线仅作预热、所有候选结果完整输出、训练交易数不足时拒绝选择。
- 首次样本外实验使用 2024-01-01 至 2025-06-30 训练、2025-07-01 至 2026-07-17 验证，股票仍为上述五只，持有 20 日并计入成本：
  - V2 由训练集选出阈值 70：训练 40 笔、平均 +4.23%；验证 37 笔、胜率 37.84%、平均 -1.49%、信号池复合 -47.72%。
  - V3 由训练集选出阈值 75：训练 24 笔、平均 +2.34%；验证 18 笔、胜率 33.33%、平均 +0.41%、信号池复合 +0.86%。
- 结论：V2 明显失去样本外有效性；V3 只表现为微弱正收益且样本少、胜率低，仍不满足上线标准。下一轮应扩大跨行业样本，并优先研究市场环境过滤和“不交易”机制，而不是在这五只股票上继续调权重。
- 已将样本扩至 19 只跨行业股票。相同切分下，V2 阈值 70 的验证集为 136 笔、平均 +0.39%；V3 阈值 75 为 64 笔、胜率 56.25%、平均 +3.03%、中位数 +0.79%、盈亏比 2.7614，其中 15 只股票平均为正、4 只为负。结果比五股实验稳定，但仍只有一次时间切分，且尚未启用真实市场环境输入，不能据此上线。
- 19 股 V3 验证期买入持有基准的股票间平均收益为 +12.82%；该数值与“每笔 20 日信号收益”口径不同，当前不能直接比较。后续报告需增加同持有周期的超额收益和简单均线基准。
- `510300` ETF 在新浪源无法解码、东方财富源连接重置；验证 `stock_zh_index_daily` 可稳定取得沪深 300 原始日线后，数据层增加显式 `index` 来源，避免把指数错误套用股票复权接口。
- 已缓存 `000300` 沪深 300指数 2024-01-02 至 2026-07-17 的 614 根原始日线，并通过测试证明 V3 scorer 在任一股票信号日不可读取未来指数行。
- 启用沪深 300 市场加分后，训练集选择从阈值 75 改为 65，验证集 127 笔平均仅 +0.32%，低于不带市场输入的 +3.03%，也低于简单均线基准的 +0.94%。因此当前“市场环境直接加进总分”设计判定为无效，不接入实时策略；下一版应把市场环境作为独立的交易许可/仓位层验证。
- 已加入固定 `close > MA20 > MA60` 简单趋势基准，并让任意研究策略复用同一个成本、入场和持有期引擎。
- 四个不重叠验证窗口的滚动复测（19 股、20 日持有、训练集选阈值）如下：

| 验证窗口 | V3 训练阈值 | V3 验证笔数/平均 | MA 验证笔数/平均 | V3 是否更优 |
|---|---:|---:|---:|---|
| 2024-10-01 至 2025-03-31 | 75 | 23 / -1.22% | 45 / -2.18% | 是 |
| 2025-04-01 至 2025-09-30 | 75 | 43 / +3.67% | 43 / +4.96% | 否 |
| 2025-10-01 至 2026-03-31 | 80 | 9 / +2.04% | 28 / -2.41% | 是，但样本少 |

- 滚动结果说明 V3 的加权平均表现优于简单均线，但仅在 2/4 个窗口胜出，且最近窗口为负；尚不具备稳定替换 V2 或上线的证据。下一策略迭代重点是减少弱市场阶段的错误交易，并保持市场状态与个股选股分离。
- 阈值搜索现在缓存每只股票每个交易日的确定性评分，多个阈值不再重复计算完整因子；缓存键包含股票代码和交易日，不跨样本泄漏收益信息。
