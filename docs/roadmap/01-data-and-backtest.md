# 阶段 1：行情仓库与回测基线

状态：`COMPLETE`
完成日期：2026-07-18

## 目标

建立可复用的本地日线仓库和无未来函数的回测器，让实时评分与历史验证共享同一份数据定义。

## 范围

- 标准化日线模型：交易日、开高低收、成交量、成交额、复权方式、来源。
- SQLite 日线表和必要唯一索引。
- AKShare 日线增量同步，失败时保留既有数据。
- 从本地仓库读取指定股票和日期区间。
- 将现有评分拆成可接受历史窗口的纯函数。
- Walk-forward 回测：信号发生后 1/5/10/20 个交易日收益。
- 基本统计：信号数、胜率、平均/中位收益、最大回撤、盈亏比。
- 命令行入口，输出中文文本和 JSON 结果。

## 非目标

- 本阶段不优化指标权重。
- 不构建浏览器页面。
- 不做分钟级回测和自动交易。

## 数据正确性原则

- 某日信号只能使用该日及之前的数据。
- 收盘策略默认在下一交易日才能成交。
- 回测必须明确前复权/后复权/不复权口径。
- 缺失、停牌和上市不足所需窗口的样本必须显式跳过。
- 交易成本参数不可隐式为零。

## 验收标准

- 相同输入重复执行得到相同结果。
- 增量同步不会产生重复日线。
- 断网时可对已缓存股票执行回测。
- 测试证明信号计算没有读取未来行。
- 至少使用合成数据验证收益、成本和最大回撤计算。
- CLI 对无数据、非法日期和 API 失败给出有界错误。

## 实施记录

- 新增 `daily_bars` 标准化日线表，唯一键为股票、交易日和复权方式。
- 新增 `market_data.py`，支持字段校验、原子 upsert、本地读取和 AKShare 同步。
- qfq 为避免除权后区间口径不一致，会刷新请求区间；raw/hfq 使用最后缓存日重叠更新。
- 新增 `backtest_engine.py`，信号收盘生成、下一交易日开盘进入，并计入双边佣金、卖出印花税和双边滑点。
- 新增 `research.py sync/backtest` 中文 CLI 和 JSON 输出。
- 现有评分拆出 `calculate_score_from_history()`，实时与回测共享同一计算入口。
- 合成数据测试覆盖无未来入场、复合收益、回撤、成本、重复 upsert 和断网保留缓存。

## 验证结果

- 离线自动化测试：23 项通过（进入阶段 2 后累计测试数继续增加）。
- 真实同步：`600519` 2024-01-02 至 2026-07-17，共 614 根 qfq 日线。
- V2 基线 20 日结果：16 笔、胜率 37.50%、平均 -0.69%、复合 -12.15%。
- 该结果仅用于验证链路，不能据单只股票判断策略优劣。
