# 阶段 10：首页信息密度与层级修正

状态：`COMPLETE`

完成日期：2026-07-30

## 目标

修正首页首屏的信息层级：让候选、持仓和可执行研究内容优先出现，把市场指数降级为紧凑背景信息，并移除没有实际信息量的营销式大标题。

## 范围

- 删除首页“先看机会，再看风险。”及其副标题，改为紧凑的今日状态栏。
- 将四个 A 股指数改为单行/紧凑行情带，保留价格、今日涨跌、5/20 日变化和 MA20 趋势状态。
- 将候选面板移到市场行情带之后的首要内容区，减少首屏滚动距离。
- 修复 SVG 走势线的默认黑色填充，保证折线只显示线条且高度受控。
- 保持现有数据源、登录、个股评分、市场采集和部署方式不变。

## 非目标

- 不删除指数数据或历史趋势计算。
- 不新增实时行情接口或改变 Web 的本地只读边界。
- 不重做荐股算法、持仓统计或导航结构。

## 设计决策

- 首页头部只保留“今日”与数据更新时间，使用单行工具栏替代大面积 Hero。
- 指数采用四列 compact tape；桌面端一行展示，窄屏再换行，不使用大面积卡片图表。
- 走势线采用无填充 SVG `polyline`，并通过内联 `fill="none"` / `stroke` 与 CSS 双重约束避免浏览器默认填充。
- “今日大盘”只作为快速环境提示，候选和持仓仍是首页主要工作区。

## 验收标准

- 首页不再出现“先看机会，再看风险。”或同等尺寸的替代营销标题。
- 桌面端首屏能看到紧凑指数行情带和至少一部分“今日重点候选”。
- 指数区域高度明显小于上一版，不出现纵向拉伸或黑色大面积 SVG。
- 首页模板在空数据、单指数和四指数数据下均能渲染；全量测试、Ruff、编译检查通过。
- 服务器备份后完成部署，Web、行情采集服务和公网健康检查正常。

## 实施记录

- 删除首页无信息量的大 Hero 标题，改为“今日 / 研究台”紧凑工具栏，并将“今日重点候选”置于指数背景信息之前。
- 将四个 A股指数从大卡片改为四列 compact tape，只保留指数名、代码、当前价、今日涨跌、20 日变化、MA20 状态和小型走势线，首屏高度显著降低。
- SVG 折线增加内联 `fill="none"` 与 CSS `!important` 约束，修复浏览器默认填充导致的黑色大面积三角形；CSS URL 增加 `?v=10`，避免旧浏览器缓存继续显示上一版样式。
- 新增页面渲染测试，断言旧 Hero 文案不存在、候选位于行情带之前、折线使用无填充 SVG；本地 Ruff、编译检查和 74 项测试全部通过。
- 服务器已先完成 SQLite 在线备份，再同步模板/样式并重启 `ashare_web`；远端 74 项测试通过，首页认证回读确认 4 个行情项、紧凑行情 CSS、旧标题为 0，公网 `/healthz` 返回 200，首页未认证返回 303。
