# A股个人量化研究平台升级路线

本目录是项目升级的唯一阶段索引。每一阶段先写清目标和验收标准，再修改代码，并在完成后记录验证结果。

## 总目标

将现有的行情提醒脚本升级为个人使用的量化研究与监控平台：策略可回测、信号可解释、数据可复用、工作日可通过浏览器安全访问，并能在普通个人服务器上稳定运行。

## 约束

- 单用户，不建设多租户和计费系统。
- 不自动下单，不连接券商交易接口。
- 优先保证策略验证与数据正确性，再增加可视化。
- 默认继续使用 SQLite；只有实测写入竞争成为瓶颈时才考虑 PostgreSQL。
- Web 页面不直接请求外部行情，仅读取本地仓库和最新计算快照。

## 通用完成标准

- 新增逻辑具有离线自动化测试。

- 外部 API 失败不会破坏已有缓存或导致无限等待。
